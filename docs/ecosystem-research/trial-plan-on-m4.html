Trial plan on the M4

You asked how to get the useful outside apps running on the M4 and connected into FliStudio, shown as if we were using them on a real video project. This is that plan. Nothing has been installed or run yet.

Verdict: 7 apps are worth trying, all walked through on d01-flivideo-tour. Try 3 first (auto-editor, Textream, HyperFrames). That takes about 7 hours of agent time and 3 GB of disk, with no FliStudio code change and no Docker. It can all run while you are still testing the pilots.

Why d01-flivideo-tour

It is the only one of the four projects with real footage: 20 Ecamm takes with word-level transcripts, 13 DJI clips (1.5 GB), 2 FliCast screen recordings, a FliCut cut, a FliEdit edit and a Teletubby script. d13, d18 and d19 have scripts and audio but no footage. d13-overlay-pilot is the second project, used only for Textream, because it has the full spoken script you are about to record.
