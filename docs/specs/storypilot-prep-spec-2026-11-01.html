03Angle first, but provisional

Your chicken-or-egg question. The evidence says both, in this order:

You: one-line angle→ Prep places + orders against it→ Contradicting sources flagged→ You: keep, sharpen or change
  • The angle is yours, in your words, dated, and can be marked provisional ("proof pending").
  • If there is no angle yet, the skill may propose three, clearly labelled as proposals. It never writes the angle field itself.
  • Evidence can challenge the angle ("3 sources cut against it"); it never quietly replaces it. That is exactly what D19 did right.
  • Without an angle, the skill still places and orders, but by time, and tells you it had no angle to work from.

04What the skill does

Placement

Every attached source goes into a story section (Why it mattered · What happened · How to tell · …), or into "suggest removing" with a reason, or into "about the tool, not the story" (the D18 build briefs).

Order

A proposed linear order through the sections, with a one-line reason per source tied to the angle ("struggle beat: the test game was already clean, so AppyStack is the real test").

Provenance, shown plainly

Each source says raw (as said or logged: a transcript, a capture) or synth (written by an AI from raw material), when each was made, and what the synth was made from.

Staleness

Every synthesis stores a source stamp: what the source looked like when the summary was made (last message time + a hash of the conversation or file). When the source has grown since, the card shows out of date — refresh. Refresh re-synthesises from the current source and updates the stamp. It's the same idea as Listen's per-paragraph audio.

06How it's built (light)

  • Skill: flivideo:storypilot-prep in the FliVideo plugin, never the legacy appydave plugin.
  • Reuses: the session-archaeology / abridge reader pattern for sessions, steno:fact-sheet's refresh mode for re-synthesis, Story Pilot's existing story.* verbs to write placement, and Listen's hash approach for staleness.
  • New data: an angle field (you only), and a source stamp + placement reason on each source in story.json.
  • Story Pilot UI: the ordered list above, the out-of-date pill, and a "contradicts angle" flag. Built by storypilot-dev after Listen.
