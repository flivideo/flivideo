Two words, one meaning each

WordMeansYou doOn Teletubby
VariantOne regeneration with a given profile set. Stable id, free-text label, its own history.Regenerate with a different structure, voice or styleA new chip, with a dot. You are not moved.
VersionA word-level edit inside one variant. A number that goes up.Change a few words and republishThe words swap in place. Same chip, same spot.

Where do versions live? Only in Story Pilot. Teletubby holds each variant's current words and shows the number in a tooltip. It has no history and no way back.

The one contract

One optional block added to the call Story Pilot already makes. Teletubby's own door owns the type. Story Pilot still never touches fli.tubby.json.

script.write {
  id: "storypilot-project",   // unchanged: one Teletubby script per video
  name, text, project, video, takeaway, source, triggers, chapters,  // unchanged
  variant: {                  // NEW, optional
    id: "main-3f9a1c2e",      // script id + profile fingerprint
    label: "Tolkien · teaching · long",
    version: 8                // Story Pilot's own version number
  }
}
When a publish arrives withTeletubby
A new variant idAdds it at the end. Chips never reorder under you.
Same id, higher versionReplaces that variant in place. Others untouched.
Identical contentDoes nothing. No write, no event.
Same id, lower versionRefuses. A late send can't roll back your words.
A script with the old unlabelled textDrops it on the first variant publish. That's how d13 moves over.

The spec

What exists, what is new

ExistsScripts with history, undo, audio. The profile. Send. Footer chips. The arrival dot. Position kept on refresh.
New in Story PilotVariant id and label worked out at publish. A label box beside Send. A publish closes the 10-second fold.
New in TeletubbyVariants stored on the transcript. Chip shows the label. Keep position by the words, not the paragraph number. Re-staging where you already are does nothing.
Fixed in FliStudiovideo.text lists variants, so "same or changed" stays true.

Calls already made

You said not to be asked, so these are decided and logged. Each is one sentence to overturn.

A variant is a chip on the strip you already use

Not a separate entry in the script list: no new control to learn, and it stays scoped to this video.

The version number is Story Pilot's own

v8 in Teletubby is row 8 in History. Several saves between publishes jump the number by that many, rather than exactly one.

The version number is not on the chip

Nothing about the take depends on it. It's in the tooltip.
