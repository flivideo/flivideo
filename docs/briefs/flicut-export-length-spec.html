The spec

What the job is

One length, one functionThe Cuts list, the editor's "Kept" stat and the export all take their length from the export plan, so they cannot disagree again.
Join before roundingKept clips that run straight on from each other in the same recording become one piece before the plan rounds to frames. D02 goes from 363 pieces to 26.
No frame twiceNo source frame appears in two pieces of the plan.
Mismatch is shownIf the exported file probes more than one frame away from the plan, the export line says so, with both numbers.
DisplayThe list keeps m:ss. The "Kept" tooltip stays "what the export will run", and now it is true.

What I checked, and what I didn't

  • The Cuts list row prints fmtDuration(p.duration) at src/renderer/src/Home.tsx:110; the number comes from outputDuration(p.timeline.clipsWithCuts) at src/main/project-store.ts:529, an exact sum (src/shared/clock.ts:41). The editor's Kept stat uses the same sum (src/renderer/src/Editor.tsx:651, shown at :959).
  • The list reads the edit through readProject → #fromDisk → relayout (project-store.ts:245-253, in place since 2026-09-27), so padding is applied before the list sums. Note #22's "no padding" is wrong for today's code.
  • The export's length is buildPlan (src/shared/export-plan.ts:50-62): each kept clip is its own piece, start rounded down and end rounded up to the 25 fps grid. Two clips that touch both claim the frame at their join. exportArms renders that plan (src/main/pipeline.ts:427, recorded at :516); ffmpeg trims video and audio per piece (export-plan.ts:150-164).
  • D02 measured: 391 clips, 363 kept, 337 kept clips that touch the one before. Exact sum 335.53 s; plan 344.48 s, matching last-arms.json and ffprobe on cutty-audio-cleanup-audio-a100.mp4 (344.48 s). The edit was last saved 00:40 UTC, before the 04:58 export, so it is the exported edit. Measured with a scratch script calling FliCut's own src/shared code; no app was started.
  • A side note: the non-contract export path reports plannedDuration as the exact sum, not the plan (src/main/index.ts:439). Same fix covers it.
  • Not checked: whether the repeated frames can be heard or seen in the D02 file. Each is 40 ms of audio and video played twice at a join inside continuous speech. If it is audible, this stops being a display job and the D02 to D07 exports carry a defect; it does not change the size of the code fix.
