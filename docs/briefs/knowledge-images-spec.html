Reference images in a video's Knowledge

Each video in FliStudio has a Knowledge group: the things an AI reads before it writes anything for that video. Today it holds dossiers, Captain's Log captures, links and notes. This adds a fifth kind, Images: screenshots, thumbnails and slides you collected while researching, each with one line saying why it helps.

Sample: D07, Buzz coding teamSize: ~45–60 min for one coderStatus: spec only, not built

What you'd see

The Knowledge panel gets an Images row, shown as thumbnails, each with its "why" line underneath. You add one by dropping or pasting an image onto the row.

The spec

What the job is

New kindimage in the knowledge group, label "Images", many per video, never "chosen"
ValueA path to the file, plus the same one-line meta.why (200 characters max) every knowledge item has
DisplayThumbnails in a grid, why line under each. FliStudio already draws image kinds this way for thumbnails, so this reuses it
Add (you)Drop or paste onto the Images row. FliStudio copies the file into the video's folder and asks for the why line
Add (an agent)Same verb agents use for the other kinds, given a file path and a why line
Who reads itAny skill that reads Knowledge, e.g. flivideo:segment-writer. It gets the path and can look at the image

Done-check (D09 form)

proofknowledge.test.ts sees 5 kinds, not 4; a test adds an image and reads it back with its why line
test_auditdev-team:audit-test-quality on the new tests
before_afterThe two panels above, as real screenshots of the D07 project
durationFrom the queue timestamps

Out of scope

  • A shared library of images used across many videos (brand level). That comes later, when B-roll becomes its own app.
  • Editing or cropping images.

What I checked, and what I didn't

  • The four kinds today: flistudio/server/src/capabilities/knowledge.ts (dossier, capture, link, note).
  • Image display already exists: flistudio/client/src/components/Resources.tsx has an image case that draws thumbnails.
  • The requirement: flivideo/docs/briefs/requirements-bundle-2026-10-09.md §2, which also says "probably brand-level storage".
  • Not checked: whether the Resources panel has any way to add an item by hand today. I found no drop or paste on it. If one already exists, the job gets smaller.

Two choices for David

Where the files live

In the video's own folder, or a brand-wide folder you can reuse across videos.

The video's folder for D09. Brand-wide belongs with the B-roll app later, and moving files then is easy.

Drop and paste in the job, or not

Without it the kind exists, but only agents can add images.

In. Otherwise there is no visible "after" for you to film.
