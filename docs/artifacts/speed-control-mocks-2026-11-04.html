Ten speed buttons become one control

Show three or five speeds around the current one; chevrons step through the rest. One component, four players. Everything below is live — click the buttons, hover for key tooltips.

Recommendation: the 3-visible window in the three small bars (Story Pilot, FliStudio, FliHub), the 5-visible only where there is room and the control is the star (FliCut sits in a toolbar row beside the badge). The chevrons are the same action as J / L, so the keys and the buttons can never disagree.
Try it: Switches every control on the page.

01The shape

The ladder is today's ten rates. The control shows a window of it centred on the current speed (pinned to the ends, so the window never shrinks). The lit button is the current speed.

03The edges

At the slowest and fastest rung the window pins to the end and the chevron on that side goes grey. Nothing jumps.

04J / K / L onto the control

No new key logic: the control calls the same pure jkl() in fli-core. The lit button just follows.
